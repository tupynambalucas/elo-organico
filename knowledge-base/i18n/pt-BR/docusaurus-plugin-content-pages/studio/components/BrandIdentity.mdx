### Estratégia Visual e Governança

A identidade visual é fundamentada no arquétipo do Homem Comum (Everyman), priorizando acessibilidade, empatia e uma orientação comunitária realista. A governança é mantida através de um sistema de design estritamente tokenizado, projetado para conformidade WCAG AAA.

#### Filosofia e Pilares Centrais

*   **Pertencimento:** Fomentar o sentimento de dono da comunidade e a participação coletiva.
*   **Simplicidade Honesta:** Operações transparentes entregues através de interfaces intuitivas e funcionais.
*   **Conexão Humana:** Manter o elo social em cada transação digital.
*   **Conceito:** "De par a par, do solo à mesa."

#### Tipografia e Engenharia de Fontes

O sistema utiliza a família de fontes Nunito (Rounded), gerenciada como um ativo centralizado no workspace `@studio` para garantir paridade entre pacotes. Os títulos são priorizados em pesos Negrito (Bold), enquanto o texto do corpo segue as especificações de peso Regular.
*   **Distribuição:** As fontes são empacotadas via `@fontsource/nunito` e injetadas automaticamente nos estilos globais através do `theme.css` centralizado.
*   **Performance:** A implementação utiliza **Fontes Variáveis** (`variable.css`) para fornecer todo o espectro de peso (200-900) com uma única requisição HTTP, otimizando os Core Web Vitals.

#### Implementação Técnica: Sistema Híbrido de Tokens

O sistema de design emprega um modelo de **Fonte Única de Verdade Híbrida (SSOT)**, unindo a lacuna entre o CSS de alta performance e a engenharia TypeScript fortemente tipada.

| Camada | Caminho do Arquivo | Finalidade Técnica |
| :--- | :--- | :--- |
| **Fonte de Verdade (TS)** | `src/tokens/colors.ts` | Objeto fortemente tipado (HEX) para componentes React, animações GSAP e materiais Three.js. |
| **Camada de Distribuição (CSS)** | `src/tokens/theme.css` | Bloco `@theme` do Tailwind CSS v4 e resets básicos para entrega no navegador com zero runtime. |
| **Registro de Ícones** | `src/icons/index.tsx` | Barrel curador de ícones FontAwesome e um wrapper padronizado de componente `Icon` (forwardRef). |
