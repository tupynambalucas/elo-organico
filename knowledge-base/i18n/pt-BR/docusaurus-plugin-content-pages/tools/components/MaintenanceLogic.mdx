### Lógica Operacional e Manutenção

Comandos padronizados são fornecidos para a manutenção da camada de automação e verificação da saúde do workspace em todo o monorepo.

| Comando | Responsabilidade de Engenharia |
| :--- | :--- |
| `pnpm typecheck` | Valida a integridade do TypeScript nos scripts e no código-fonte do MCP. |
| `pnpm build` | Build completo de produção incluindo servidores MCP e ferramentas de automação. |
| `pnpm clean` | Manutenção agressiva do workspace usando `npkill` para podar dependências legadas. |

#### Orquestração de Workspace

| Comando | Ação de Engenharia |
| :--- | :--- |
| `pnpm mcp:up` | Inicializa a stack completa do Dockerized gateway e backend MCP. |
| `pnpm mcp:down` | Derruba o gateway e o ambiente de containers do MCP. |
| `pnpm mcp:reset` | Limpeza agressiva da stack (volumes removidos) seguida por rebuild completo dos containers. |

#### Estrutura do Workspace

*   `tools/mcp/compose.yaml`: Define os serviços, dependências, volumes e redes bridge dos containers.
*   `tools/mcp/gateway/`: Contém o servidor HTTP proxy router Fastify v5 (`server.ts` e sua Dockerfile).
*   `tools/mcp/infrastructure/`: Contém as Dockerfiles multi-estágio individuais e o wrapper `sse-adapter.ts` sem dependências externas.
*   `tools/mcp/config/`: Gerencia ambientes específicos de contexto e configurações de segredos (arquivos de template `.env.*.example`).
